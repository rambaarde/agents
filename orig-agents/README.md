# Legacy AI Agent Personas

> **Note:** This directory contains the **original foundational agent personas** that served as the inspiration and base for the expanded [Contains Studio AI Agents](../README.md) system. These agents are preserved for reference, backward compatibility, and archival purposes.

## 📚 About This Collection

These are the **original 8 agent personas** that pioneered the concept of specialized AI assistants for rapid development. While they remain functional and useful, they have been significantly expanded upon in the main agent ecosystem located in the parent directory.

## 🔄 Migration Path

If you're using these legacy agents, consider exploring the expanded agent system which includes:

- **More specialized roles** (40+ agents vs 8)
- **Enhanced collaboration patterns** between agents
- **Modern tech stack recommendations**
- **Proactive triggering mechanisms**
- **Department-based organization**
- **Detailed usage examples with commentary**

## 🎯 When to Use Legacy Agents

These original agents remain useful when:

1. **You prefer broader, generalist agents** over specialized ones
2. **Your IDE/environment doesn't support the new YAML frontmatter format**
3. **You're working on a project that references these specific personas**
4. **You need simpler, less opinionated agent instructions**

## 🚀 Upgrading to the New System

To transition to the expanded agent system:

1. **Review the [main README](../README.md)** for the full agent catalog
2. **Explore department-specific agents** that match your current needs
3. **Try the new specialized agents** alongside legacy ones to compare
4. **Gradually adopt** agents that provide the most value for your workflow
5. **Provide feedback** on what works better in either system
